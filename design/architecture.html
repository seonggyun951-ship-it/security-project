개인정보 DB 격리 — 왜 이렇게

별도 경계 + 엔드포인트 + DB 접근제어. 네트워크를 통째로 잇는 피어링이 아니라, DB 서비스 하나만 엔드포인트로 내주고 그 앞에 접근제어 게이트웨이를 둔다.
· AWS — 별도 vpc-pii + PrivateLink + DB 접근제어 GW
· GCP — 별도 virtual-corp-pii + PSC + DB 접근제어 GW
· 접근제어 GW 예시 — DB SAFER (모든 접속·쿼리 기록 · 정책통제 · 마스킹)

개인정보보호법 안전성 확보조치 — 개인정보처리시스템 접속기록 2년 이상 보관(고유식별·민감정보 또는 5만명 이상). ISMS-P 접근통제·접근기록 요건에 대응.
🚨 긴급 접속 절차 — DB SAFER 장애 시 → 클라우드 콘솔 직접 접속 (CloudTrail / Audit Logs로 별도 기록, 사후 감사 대상)
