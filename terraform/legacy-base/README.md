# legacy-base — 적용하지 않는 옛 기본 인프라 코드

2026-08-05에 처음 만든 기본 인프라(`security-vpc` 10.0.0.0/16, 서브넷 2개, IGW,
SSH·HTTP를 인터넷 전체에 연 SG, t3.micro EC2 2대)다.

8월에 환경별 VPC(`terraform/envs/`)로 옮기면서 리소스는 지웠는데, 코드가
에이전트가 apply하는 `terraform/`에 그대로 남아 있었다. 그래서 에이전트가 신청을
하나 apply할 때마다 이 인프라 전체를 다시 만들려고 했다.

2026-10-07 서브넷 신청(dev-demo-a)에서 드러났다. VPC 한도(5개)가 꽉 차서 VPC 생성에서
막혔기 때문에 EC2(유료)까지는 가지 않았다. 신청한 서브넷만 먼저 만들어진 채 실패로 끝났다.

Terraform은 하위 폴더의 `.tf`를 읽지 않으므로 여기 두면 적용되지 않는다.
참고용으로만 남긴다. 다시 쓰려면 `terraform/envs/` 방식으로 옮겨 쓴다 —
에이전트 폴더(`terraform/`)에는 provider와 신청이 만든 `req_*.tf`만 둔다.
